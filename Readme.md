## 📜 Project: API Pharmacy - Java Training + Spring Boot 📜

This project is part of a Java training program and involves building a
robust API for a pharmacy system. It also includes a React-based frontend 
for interaction with the API.

---

## ⚡ 🛑 The Challenge

The main objective of this challenge is to practice and apply key tools
for web development and API construction, including:

- **Java**
- **Spring Boot**
- **React**

---

## 🔺 Technologies Used 🎯

This project was built using the following technologies and tools:

- **Backend:** Java, Spring Boot
- **Frontend:** React
- **Database:** MySQL (or specify the database you used)
- **Version Control:** Git and GitHub
- **Development Tools:** IntelliJ IDEA, Postman (for API testing)
